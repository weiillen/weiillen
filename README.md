## About me

I enjoy projects that make abstract EECS ideas observable: measuring cache behavior, tracing network protocols, verifying RTL waveforms, testing model failure cases, and documenting what the evidence actually supports.

- Building across **computer architecture, high-performance computing, networks, digital design, and applied machine learning**.
- Comfortable working with **C, C++, Python, Verilog, Linux tooling, Jupyter, and simulation/profiling workflows**.
- I value **correctness before optimization**, reproducible experiments, honest limitations, and preserving the original engineering record.
- Currently strengthening my foundations in **integrated-circuit design, semiconductor devices, and secure systems**.
