# Setup

1. Create a public GitHub repository named exactly `weiillen`.
2. Upload `README.md` to the repository root.
3. Upload the `assets` folder beside it.
4. Commit the files. GitHub will display the README on your profile.

The uploaded image used a `.gif` filename but contains PNG image data, so it is stored as `assets/profile-banner.png` to ensure reliable rendering on GitHub.
